# Список изменений

Изменения WEBOS-FW-BLOCK на русском.  Заголовки разделов остаются на английском, как в исходном [CHANGELOG.md](../CHANGELOG.md), где есть все версии.

## [1.0.0] - 2026-11-20

### Changed

- **1.0.0: блокировка готова.**  Для каждого найденного пути обновления (собственная проверка обновлений, LG Remote Support, приложения на телефоне и загрузки, которые всё равно начались) есть своя блокировка.  Приложение работает вместе с Homebrew Channel и LG-USB-2-ETH0, делает резервную копию перед любыми изменениями и обновляется только из подписанных выпусков.  Пока оно проверено на одном телевизоре, поэтому отчёты с других телевизоров по-прежнему приветствуются.

### Fixed

- **Тексты на испанском и русском.**  Несколько текстов на русском переформулированы.

### Security

- **Обновление проверяется дважды перед установкой.**  Теперь и скрипт перед передачей в Homebrew Channel проверяет, что загрузка является IPK этого приложения, из его собственных выпусков на GitHub и ровно той версии, что предложена.  Раньше это проверяла только проверка обновлений.

## [0.1.2] - 2026-11-20

### Added

- **Что нового, на вашем языке.**  После обновления, и когда приложение предлагает обновление, примечания к выпуску показываются на испанском или русском, если приложение переключено на один из них.  Переведённые примечания подписываются вместе с выпуском и проверяются так же, прежде чем показаться.

### Fixed

- **Больше нет «не удалось связаться с GitHub» при первом запуске.**  Первая проверка могла потерять ответ GitHub или начаться до того, как сеть телевизора была готова.  Теперь приложение держит каждый запрос до ответа и несколько раз тихо повторяет проверку, которая не дошла до GitHub, прежде чем сообщить об этом.
